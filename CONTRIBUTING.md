# Contributing

Contributions are welcome. Keep the extension generic and close to the public Box3D API.

- Do not copy code from repositories that do not grant a compatible license.
- Do not add code or assets from private or employer-owned game projects without explicit permission.
- Keep game-specific destruction, damage, scoring, pooling, and scene-management behavior outside the extension.
- Update documentation and the example when changing the Lua API.
- Upstream Box3D upgrades must change `UPSTREAM.json`, refresh the official public headers, and pass all platform builds.

By contributing, you agree that your contribution is licensed under this repository's MIT License.
